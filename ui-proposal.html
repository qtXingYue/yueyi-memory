3键盘与无障碍基线

现状：抽屉 / 编辑器 / 命令面板都没有 dialog 语义，无焦点陷阱与焦点归还；批量选择的"复选框"是个 div；卡片操作条只靠 hover 出现；引导弹窗无法跳过。

浮层 Esc 栈（建议实现）

在 store 里维护一个栈，Esc 只弹最上层，关闭后焦点还给打开它的元素。

区域框选覆盖层z-200
命令面板 Ctrl+Kz-[?] 无 role
记忆详情抽屉无 aria-modal
新建记忆编辑器唯一处理 Esc
首次引导无跳过 / Esc 无效
  • 统一 role="dialog" aria-modal="true" aria-labelledby，配 useFocusTrap（进入锁焦、关闭归还），一个 hook 覆盖三处。
  • 命令面板补 listbox 语义：role="listbox" + aria-activedescendant，光标项 scrollIntoView({block:'nearest'})，鼠标 hover 不再污染键盘光标。
  • 批量选择换成 role="checkbox" aria-checked（或视觉隐藏的 native input），可 Tab 到、可读屏播报。
  • hover-only 操作条改为 :hover + :focus-within：合集卡与记忆卡的编辑/删除键盘可达。
  • 引导加"跳过"并接 Esc；Settings 的开关补 role="switch" aria-checked，表单控件补 htmlFor。
