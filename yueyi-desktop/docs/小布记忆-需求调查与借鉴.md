# 月忆需求调查（桌面场景）：以小布记忆为参照

> 调查日期：2026-10-22　｜　对象：月忆 Desktop（Tauri 2 + Rust + React + SQLite）
> 参照：OPPO 小布记忆 / AI 一键闪记（ColorOS 15 → 17）
> **范围约束：只做电脑端真实成立的场景。记账/账单、取餐码、旅行地图、相机参数这类手机生活场景一律不做。**

**结论先行**：月忆已经把「记 → 管 → 搜 → 问」跑通，但强在截图与问答，弱在**结构化**与**主动**。桌面端最值得抄的是小布的「结构化字段 + 智能合集 + 主动回顾」三层，而不是它的生活场景。

---

## 最该做的 5 件事（TL;DR）

1. **结构化字段 + 行动卡**：从截图/文档/网页里抽出**链接、文件路径、截止时间、会议时间、代码语言、人名、待办**，卡片上能直接打开、定位文件、复制、加日历、设提醒。
2. **智能合集 2.0**：新建「课程/项目/论文」合集只写名字，AI 自动关联历史记忆并生成精华总结；新记忆自动归集。
3. **全局捕获**：剪贴板监听、拖拽文件/文件夹、选中文字入库，把记录成本降到接近零。
4. **检索升级**：FTS5 + 类型/合集/文件格式/时间过滤 + 「上周 / 上个月」自然语言时间。
5. **收工简报 / 周复盘**：每天 18:30 一条「今天存了什么、什么还没整理、明天到期什么」，周日生成周报草稿。

## 一、小布记忆做对了什么（以及哪些不适合桌面）

OPPO AI 把小布记忆的价值拆成四点：**轻松记、方便管、随心搜、主动推**，并明确说「主动推还没完全发力，是下一步重点」。

| 能力域 | 小布的做法 | 桌面适用性 | 月忆要不要 |
|---|---|---|---|
| 轻松记 | 实体闪记键 / 三指上滑 / 语音；抓屏幕图文、多图 | 中：手势换成快捷键 | 要（快捷键 + 剪贴板 + 拖拽） |
| 结构化理解 | 提取时间、金额、商户、地址、票务、联系方式；视频章节摘要 | **高**：桌面资料同样需要结构化 | 要，但字段换成桌面语义 |
| 方便管 | 智能合集：输入名称自动关联并生成精华总结 | **高** | 要，重点抄 |
| 随心搜 | 自然语言检索、复合条件、记忆问答 | **高** | 要，补时间语义与过滤 |
| 主动推 | 小布建议、到站提醒、意图闪记、小布 Next | 中：手机靠场景，桌面靠工作节奏 | 要，改成收工简报/周复盘 |
| 记账/账单 | 支付截图自动成账、月度统计 | **低：桌面不成立** | **不做** |
| 取餐码/锁屏岛/旅行地图/相机参数 | 手机生态专属 | **无** | **不做** |
| 隐私与同步 | 端侧沙箱、脱敏、云同步可关 | 高 | 先做本地，同步后置 |

### 小布也没做好的地方（桌面机会）

- 搜索不懂「人」和「场景」：相册里搜「我跟某某的照片」找不到，因为不知道某某是谁；
- 视频理解只到章节，画面里的图表、手势识别不了；
- 跨账户数据不能合并，也不支持「比上月增长多少」这类计算（记账能力本身不在桌面范围）；
- 云同步要登录账号，纯本地用户只能自己扛。

这些短板里，**「搜索不懂人/项目/上下文」是桌面端最该补的**：工作记忆的核心不是金额，是「哪个项目、哪个人、哪份文件、什么时候到期」。

## 二、月忆现状盘点

### 2.1 已具备

| 模块 | 现状 |
|---|---|
| 捕获 | 全屏截图、活动窗口截图、区域框选、速记条、剪贴板保存、新建记忆 |
| 理解 | WinRT 离线 OCR；DeepSeek 生成标题、摘要、标签、合集分类（4 次调用） |
| 组织 | 合集 CRUD + 拖拽排序、标签、时间线分组、批量移动/删除 |
| 检索 | 关键词包含匹配、搜索历史、相关记忆（标签交集） |
| 问答 | 基于检索片段的 AI 问答，带 [1][2] 引用，无相关内容时明确拒答 |
| 体验 | 全局快捷键、命令面板、托盘、明暗主题、密度模式、UI 实验室 |
| 数据 | SQLite 本地优先，8 张表；仅用户触发 AI 时发送相关片段 |

### 2.2 桌面场景下的真实缺口

| 价值点 | 月忆得分 | 说明 |
|---|---|---|
| 轻松记 | ★★★☆☆ | 截图够快，但**复制文字、拖文件、批量图片**还要手动新建 |
| 方便管 | ★★☆☆☆ | 合集是空壳：不自动归集、没有合集摘要 |
| 随心搜 | ★★★☆☆ | 只能字面匹配；**没有时间语义、文件格式、项目/合集过滤** |
| 主动推 | ☆☆☆☆☆ | 没有回顾、没有到期提醒、没有「继续上次」 |
| 结构化 | ★☆☆☆☆ | AI 只产出标题/摘要/标签/合集，**不产出任何可执行字段** |

### 2.3 桌面用户的六个真实任务（JTBD）

1. **「看到就想存」**：网页段落、报错、代码、PDF——复制一段文字反而要新建记忆再粘贴。
2. **「别让我整理」**：AI 分了合集，但合集里没有摘要，也关联不到旧资料。
3. **「我要找的是那件事」**：搜「上周的论文」只能匹配字面「上周」，找不到上周的 PDF。
4. **「这条记忆里有件事要做」**：会议时间、DDL、代码路径、下载链接，存完是死的，不能一键加日历/打开文件/复制。
5. **「这个项目我存过什么」**：没有项目视图，合集只是标签，不能按项目聚合。
6. **「帮我回忆一下」**：没有每日/每周回顾，也没有「你三个月前存过类似的东西」。

## 三、借鉴需求清单（按桌面场景重排）

工作量按单人 + AI 辅助估算。

### P0（下一阶段，约 3 周）

#### R1 结构化字段 + 行动卡 —— 让记忆能「用」
- **字段（桌面语义）**：
  - 通用：`kind`（note/link/snippet/file/schedule/task/contact/reference）、`title`、`url`、`file_path`
  - 时间：`deadline`、`event_start`、`event_end`
  - 工作：`project`、`people`、`todo`、`version`、`code_lang`
  - 联系方式：`email`、`phone`
- **需求**：
  1. AI 分析输出扩展 JSON，解析失败时正则兜底；
  2. 卡片显示字段 chips（`#课程` · `周五 14:00` · `src/main.rs`）；
  3. 行动按钮：打开链接、在文件夹中显示、复制代码/路径、加入日历（.ics）、设提醒、建待办。
- **验收**：会议通知截图能生成 .ics；代码截图识别语言并可复制；本地文件路径能一键定位；链接一键打开。
- **技术**：`memory_fields(memory_id, key, value, normalized, confidence)`；`kind` 驱动卡片模板；提醒先走 Windows 本地通知 + 应用内待办。

#### R2 智能合集 2.0 —— 项目/课程自己长出来
- **用户故事**：新建「编译原理」合集只写名字；月忆把历史里的课件、作业、报错截图、论文自动关联，并生成一段课程脉络总结。
- **需求**：
  1. 建合集可填「一句话目标」；
  2. 后台扫描历史，返回建议关联列表（可一键全收）；
  3. 合集页顶部生成 150–300 字结构化总结（主题/关键资料/待办/时间线）；
  4. 新记忆入库自动判定归属：置信度 ≥0.7 自动加入，0.4–0.7 进「待确认」。
- **验收**：新建「编译原理」30 秒内关联 ≥5 条相关记忆；总结包含主题与关键文件；误收率 <10%。
- **技术**：`collection_memories(collection_id, memory_id, score, source, status)` + `collections.summary`；分析 worker 增加一次归集判定；合集页加总结卡。

#### R3 全局捕获 —— 把「记」的门槛降到零
- **需求**：
  1. 剪贴板监听（可关）：复制文本/图片/文件路径后，托盘提示「存入月忆」；
  2. 拖拽入窗：图片、PDF、DOCX、Markdown、代码文件批量入库；
  3. 选中文字捕获：快捷键读取当前选区（模拟复制后入库，失败则提示复制）；
  4. 复制 URL 后自动抓标题（可选联网）。
- **验收**：复制一段文字后一次快捷键入库；拖 5 个文件批量入库；重复内容自动去重；剪贴板图片可直接 OCR。
- **技术**：`tauri-plugin-clipboard-manager` 已有；Windows 拖放事件；补 `memories.content_hash` 唯一索引做去重（目前没有）。

#### R4 检索升级 —— 从「字面匹配」到「条件查询」
- **需求**：
  1. SQLite FTS5（`tokenize='trigram'` 对中文友好）+ 触发器同步；
  2. 结构化过滤：类型、合集、标签、文件扩展名、来源、时间范围、是否有待办；
  3. 自然语言时间：今天/本周/上周/上个月/最近 N 天/去年；
  4. 查询语法：`type:pdf 上周`、`tag:课程 编译`、`file:.rs`；
  5. 混合排序：BM25 + 标签命中 + 时间衰减；搜索页显示可移除的过滤 chip。
- **验收**：1 万条记忆 P95 <80ms；「上周关于编译原理的 PDF」首条命中正确；问答引用仍可跳原文。
- **技术**：FTS5 虚表 + `bm25()`；时间解析用规则表（不调模型）；保留 LIKE 兜底。

#### R5 收工简报 / 周复盘 —— 桌面版的「主动推」
- **需求**：
  1. 每天 18:30 一条简报：今天存了什么、几条待整理、明天有什么到期、一条旧记忆重现；
  2. 周日生成周报草稿：本周主题、新增资料、未完成待办、常用合集；
  3. Windows toast 可点击直达；默认每天 1 条，可关。
- **验收**：简报能正确统计当日新增；点击跳到对应记忆/合集；关闭后不再打扰。
- **技术**：后台定时任务 + 本地通知；用现有 `daily_summary` prompt 扩展；不调用模型也能出基础版，调模型出「主题归纳」。

### P1（1–2 个月）

| 编号 | 需求 | 桌面价值 | 验收 |
|---|---|---|---|
| R6 | 文档解析（PDF/DOCX/MD） | 论文、合同、课件直接入库并摘要 | 30 页 PDF 生成 5 条要点 |
| R7 | 代码片段增强 | 语言识别、语法高亮、复制原文、关联文件路径 | 代码截图识别语言 ≥90% |
| R8 | 记忆关联 2.0 | 分析时从候选里选 3 条关联；后续接本地 embedding | 详情页「相关记忆」主观命中 ≥70% |
| R9 | 项目视图 | 以项目聚合记忆、文件、待办、时间线 | 一个项目页能看到全部上下文 |
| R10 | 浏览器扩展 / 划词捕获 | 网页正文、选中段落、图片一键入库 | 扩展一键入库带标题与 URL |
| R11 | 可读导出 | 单条/合集导出 Markdown、长图卡片 | 合集导出含摘要与来源链接 |

### P2（季度级）

- **R12 隐私保险箱**：身份证/银行卡/手机号正则脱敏；单条锁定；本地加密。
- **R13 多设备同步**：先「导出/导入 + WebDAV 快照」，再做增量同步与冲突解决。
- **R14 语音速记**：全局按住说话，本地 Whisper.cpp 或系统语音，转文字后走速记流程。
- **R15 主动建议**：基于项目/时间/重复主题的「你可能要…」，必须极克制，做不好就是骚扰。
- **R16 视频章节**：ffmpeg 抽帧 + 字幕/ASR + 章节摘要；成本高，等文档解析稳定后再评估。

## 四、明确不做

| 功能 | 理由 |
|---|---|
| 记账 / 账单合集 | 手机支付场景在桌面不成立；桌面票据需求是报销，不是日常记账 |
| 取餐码 / 锁屏岛 / 流体云 | 手机生态专属 |
| 旅行合集 / 地图路线 | 依赖地图与定位生态，桌面使用频次低 |
| 相机参数导入 | 与桌面无关 |
| 实体闪记键 / 三指上滑 | 桌面已有全局快捷键，不需要 |
| 端侧大模型 | 体积与算力门槛高，按需调用 + 本地 OCR 更现实 |
| 全量云同步 | 隐私敏感、工程量大，先做可读导出 |

## 五、桌面端差异化

小布是「手机上的生活记忆」，月忆应该做「桌面上的工作记忆」：

- **键盘优先**：捕获、搜索、整理全都能不摸鼠标；
- **文件友好**：PDF、代码、Markdown、表格、截图混在一起也能统一检索；
- **批量处理**：多选、拖拽、导出、归档是桌面天然优势；
- **项目上下文**：以项目/课程聚合，而不是按 App 分；
- **来源可信**：每条 AI 回答必须能点回原文；
- **本地优先**：默认不上传，AI 只发相关片段。

三个切入场景：
1. **学生/开发者资料**：课件、论文 PDF、代码片段、报错截图、网页教程；
2. **项目上下文**：需求文档、会议记录、参考链接、待办；
3. **周报与复盘**：本周捕获 → 自动生成周报草稿。

## 七、风险与边界

| 风险 | 说明 | 缓解 |
|---|---|---|
| AI JSON 不稳定 | 结构化字段依赖模型输出 | 严格 schema + 正则兜底 + 失败降级为纯文本 |
| 调用成本 | 每条记忆多次 LLM 调用 | 合并为一次结构化分析；缓存；只对相关片段提问 |
| OCR 错误 | 截图模糊/小字 | 保留原图；低置信度字段标「待确认」 |
| 中文分词 | FTS5 默认分词对中文差 | trigram tokenizer；必要时上 jieba |
| 选中文字捕获 | 模拟复制可能干扰剪贴板 | 读取后恢复剪贴板；失败提示手动复制 |
| 同步冲突 | 多设备写入 | 先只做快照导入导出；增量同步用 updated_at + 设备 ID |
| 主动打扰 | 通知过多会被关掉 | 默认每天 1 条、可关、只推有行动价值的内容 |

## 八、衡量指标

- **捕获效率**：触发到入库 P95 < 2 秒；捕获成功率 > 98%；重复率 < 2%。
- **整理质量**：AI 整理完成率 > 95%；合集误收率 < 10%；字段准确率 > 85%。
- **检索效果**：搜索首条命中率（人工抽检）> 80%；P95 < 80ms。
- **使用粘性**：周新增记忆 ≥ 20 条；7 日留存 > 40%；每周至少 3 次搜索/问答。
- **主动价值**：简报打开率 > 30%，关闭通知率 < 5%。
